Automation (launchd)

Scheduled jobs are LaunchAgents in ~/Library/LaunchAgents/, not cron.

JobDefaultBehavior
Daily checkOn · 09:15Read-only Homebrew refresh + log
Weekly jobOffRuns only if you enable it
Allow weekly upgradesOffOpt-in: weekly job may run mm upgrade
mm schedule enable daily
mm schedule enable weekly
mm config set weekly_upgrade true
mm schedule status

Safety

  • No implicit sudo
  • No deleting user files
  • status, doctor, security, logs, version stay read-only
  • Upgrades only via mm upgrade or the weekly opt-in
