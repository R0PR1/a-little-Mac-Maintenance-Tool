# Agent instructions

Start by reading `CURSOR.md` in full.

Implement the project incrementally and keep the repository executable at every step.

Before considering a task complete, run:

```bash
make syntax
make lint
make test
```

If ShellCheck or Bats are unavailable locally, install them through Homebrew on macOS. Do not weaken lint rules to make failures disappear; fix the implementation.

Prioritize the milestones in `ROADMAP.md`.
